# Module Responsibilities

lipsync.py

Coordinates the lip sync process.

Receives audio.

Requests amplitude values.

Updates AvatarManager.

Nothing else.

------------------------------------

audio_analyzer.py

Reads generated audio.

Produces normalized amplitude values.

No avatar logic.

No websocket.

------------------------------------

mouth_mapper.py

Converts normalized amplitude

↓

Mouth Open value

No networking.

No GUI.

# AvatarManager

AvatarManager remains the only module

Lip Sync must never call VTubeStudioClient directly.

# Audio Source

Reuse the audio generated by Gemini Native TTS.

Do NOT regenerate audio.

Do NOT perform another TTS request.

Only analyze the existing audio.

---

# Audio Analysis

Only simple amplitude analysis is required.

No phoneme detection.

No viseme generation.

No AI.

No ML.

No speech recognition.

Simple RMS / amplitude analysis is sufficient.

---

# Animation Independence Policy

The avatar animation system consists of multiple independent layers.

Examples:

Expression Layer

Lip Sync Layer

Eye Blink Layer

Breathing Layer

Future Emotion Layer

Each layer controls only its own parameters.

One animation layer must never overwrite another.

AvatarManager is responsible for merging all active animation layers before sending parameter updates to VTube Studio.

This architecture prevents future conflicts when multiple animations occur simultaneously.
