# Module Responsibilities

avatar_manager.py

Coordinates avatar behavior.

Receives events.

Calls Avatar Adapter.

Contains no websocket implementation.

------------------------------------

vtube.py

Implements VTube Studio API.

Responsible only for:

Connection

Authentication

Sending API requests

Receiving responses

Nothing else.

------------------------------------

expression.py

Stores available expressions.

Maps Companion emotions to avatar expressions.

Contains no websocket code.

------------------------------------

parameter_mapper.py

Maps logical emotions into VTube Studio parameters.

No networking.

No GUI.

------------------------------------

lipsync.py

Reserved.

Do NOT implement lip sync.

Leave architecture ready.

# Avatar Independence Policy

The avatar is never the source of truth.

The source of truth is always AICompanion.

AICompanion decides:

- reply
- logical emotion
- logical state

The Avatar Layer only renders those decisions visually.

If the avatar disconnects,

AICompanion must continue functioning normally.

The application should be fully usable even when VTube Studio is closed.

Avatar support is optional.

Conversation is mandatory.
