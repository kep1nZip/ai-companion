# Objective

Introduce Autonomous Companion.

Autonomous Companion allows Arona to initiate conversations naturally.

Autonomous Companion never generates replies.

Autonomous Companion never replaces Gemini.

Autonomous Companion only determines whether Arona should begin a conversation.

# Autonomous Permission Policy

Autonomous never forces conversation.

Autonomous only evaluates whether conversation is appropriate.

YES

or

NO

Nothing else.

# Decision Score Policy

Autonomous evaluates

Idle Time

Relationship

Mood

Energy

Curiosity

Initiative

Routine

Vision Context

Each factor contributes to a weighted decision score.

The score determines whether Arona may initiate conversation.

No single factor guarantees conversation.

# Conversation Ownership Policy

Autonomous never owns conversation.

Companion always owns conversation.

Gemini always generates natural language.

Autonomous never creates reply text.

# Suppression Policy

Autonomous must suppress itself when

Teacher is typing

Teacher is speaking

Teacher is using microphone

Teacher is in continuous conversation

Teacher is presenting

Teacher is coding intensely (Vision)

Teacher recently dismissed Arona
