# Objective

Introduce the Internal State System.

Internal State represents Arona's long-term condition.

Unlike Emotion, Internal State changes slowly.

Unlike Relationship, Internal State belongs only to Arona.

Internal State influences future behavior.

It never generates responses.

Gemini remains responsible for language generation.
