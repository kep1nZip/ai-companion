# Objective

Introduce a natural Idle Animation system.

Idle Animation makes Arona appear alive even when no conversation is happening.

This system is purely visual.

It does NOT affect AI reasoning.

It does NOT generate responses.

It does NOT modify memory.

---

# Important

Idle Animation is NOT Emotion.

Idle Animation is NOT Lip Sync.

Idle Animation is NOT Expression.

Idle Animation is a dedicated animation layer.

---

# Animation Layers

The avatar animation system consists of independent layers.

Idle Layer

Lip Sync Layer

Expression Layer

Emotion Layer (future)

Motion Layer (future)

Each layer controls only its own animation.

No layer may overwrite another.

AvatarManager merges all active layers before sending parameters to VTube Studio.

# Responsibilities

idle.py

Coordinates idle animations.

Starts and stops the scheduler.

Owns no avatar logic.

Owns no websocket logic.

Owns no GUI logic.

---

blink.py

Responsible only for blinking.

Features

Random interval

Natural blink duration

Optional double blink support

No networking.

No behavior logic.

No AI logic.

---

breathing.py

Responsible only for breathing animation.

Uses slow periodic movement.

Must support models without breathing parameters.

Fallback gracefully if unavailable.

---

idle_scheduler.py

Schedules idle events.

Examples

Blink

Breathing

Future

Head movement

Body sway

Hair movement

Tail movement

No animation logic.

Only scheduling.

---

animation_state.py

Represents currently active animation layers.

Example

Idle Active

Blink Active

Talking

Expression

Future Motion

Used only by AvatarManager.

---

# Scheduling

Blink interval must NOT be fixed.

Use randomized timing.

Recommended

4–9 seconds

Breathing should remain continuous.

Avoid robotic timing.

---

# Behavior Integration

Behavior Engine may influence Idle Animation.

Examples

Mood = Sleepy

↓

Blink more frequently

↓

Longer eye closure

Mood = Excited

↓

Faster breathing

↓

Shorter blink duration

Mood = Calm

↓

Slow breathing

↓

Normal blink interval

Behavior Engine provides state only.

Idle Animation decides animation.

---

# AvatarManager Integration

Idle Animation must never communicate with VTube Studio directly.

Flow

Idle Animation

↓

AvatarManager

↓

Parameter Mapper

↓

VTube Studio Client

AvatarManager remains the only module allowed to send avatar parameters.

---

# GUI

No GUI changes required.

Qt imports remain inside ui/.

Idle Animation must remain backend independent.

---

# Voice Integration

Idle Animation continues while Arona is speaking.

Lip Sync and Idle must run simultaneously.

Lip Sync controls only mouth.

Idle controls only idle parameters.

No conflicts.
