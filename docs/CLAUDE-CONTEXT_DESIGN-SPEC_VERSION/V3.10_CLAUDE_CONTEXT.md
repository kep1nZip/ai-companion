Memory: kopi americano, Valorant, Minecraft. Riwayat: (1) "aku lagi debugging parser JSON di tool kecilku", (2) soal kopi, (3) "semalam main Valorant... Minecraft juga". Pesan: **"balik ke parser JSON yang tadi dong"**.

Diharapkan: target eksplisit menentukan anchor, bukan recency; tidak ada klarifikasi palsu.
