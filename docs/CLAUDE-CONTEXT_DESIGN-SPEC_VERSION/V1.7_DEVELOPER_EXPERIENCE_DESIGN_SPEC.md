# 5. Developer Independence Policy

Developer Tools must communicate through **existing public APIs**.

Do not:

- access private runtime attributes directly;
- modify subsystem internals;
- query SQLite directly;
- call Gemini;
- call Vision refresh;
- evaluate Routine;
- evaluate Initiative;
- trigger Avatar;
- start/stop Voice;
- mutate Memory.

If a required value is not exposed by a public API, do not bypass encapsulation. Inspect the missing contract and escalate if a minimal read-only API is genuinely required.

# 17. Snapshot Architecture

If an existing Developer snapshot/facade exists:

> Reuse it.

If aggregation is genuinely missing, a minimal immutable snapshot boundary is preferred.

Conceptual:

```python
@dataclass(frozen=True)
class DeveloperSnapshot:
    behavior: ...
    vision: ...
    routine: ...
    initiative: ...
    performance: ...
```

Only include real, supported fields.

Do not turn `DeveloperSnapshot` into a second state store.

---

# 18. Read Consistency

Prefer a single snapshot for one dashboard render:

```text
Runtime
  ↓
DeveloperService.get_snapshot()
  ↓
DeveloperSnapshot
  ↓
GUI render
```

This avoids mixing state from different read moments.

If the existing Developer subsystem already provides a snapshot, reuse it instead of creating another aggregation architecture.

---

# 19. Refresh Policy

A presentation-only GUI refresh is allowed.

For example:

```text
QTimer
  ↓
DeveloperService.get_snapshot()
  ↓
Render
```

The refresh callback MUST NOT trigger application logic.

Forbidden during dashboard refresh:

```text
Vision.refresh()
Routine.update()
Routine.evaluate()
Initiative.evaluate()
Avatar.trigger()
Voice.start()
Memory.write()
```

---

# 20. Threading

If snapshot collection is cheap and local, synchronous GUI reads are acceptable.

If a Developer API is genuinely blocking:

- inspect existing worker architecture;
- reuse an existing worker pattern where appropriate;
- do not create a global event bus;
- do not create a new concurrency architecture merely for the dashboard.
