# Audio Independence

Speech components must remain independent.

Recorder should never know about Gemini.

Whisper should never know about the GUI.

TTS should never know about playback.

Player should never know about AICompanion.

VoiceManager is the only module responsible for coordinating the complete voice pipeline.

This separation ensures that future features such as:

- Live2D lip-sync
- VTube Studio
- Emotion Engine
- Streaming TTS
- Streaming STT

can be integrated without modifying existing speech modules.

# Module Responsibilities

recorder.py

Only records microphone audio.

No STT.

No Gemini.

No GUI logic.

------------------------------------

whisper.py

Converts audio into text.

Only Speech-to-Text.

No GUI.

No Gemini.

------------------------------------

tts.py

Converts text into speech.

Only TTS.

No playback.

------------------------------------

player.py

Plays audio.

No Gemini.

No TTS.

No recording.

------------------------------------

voice_manager.py

Coordinates:

Recorder

↓

STT

↓

AICompanion

↓

TTS

↓

Player

VoiceManager becomes the speech orchestrator.

# Error Handling

Voice errors must never crash the application.

Possible failures:

No microphone

Permission denied

Recording cancelled

Whisper failure

Gemini quota exceeded

Gemini TTS failure

Playback failure

Recover gracefully.

Return to Idle state.
