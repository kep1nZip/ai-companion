# 6. Why Vision Is Still Gemini

Vision has NOT been migrated to Local Provider yet.

Known reasons:

1. Current LocalProvider translates the existing text-content contract and does not safely carry image parts yet.
2. Forcing the current local adapter to Vision could silently discard image data.
3. Auto Vision and chat would compete for the same LM Studio/local inference resources.
4. Existing Vision output parsing has been validated with Gemini and has not yet been validated with the local model.

Therefore:

> **Step 7 MUST NOT attempt to migrate Vision to the local provider.**

Vision remains Gemini during this regression milestone.

---

# 7. Why Memory Extraction Is Still Gemini

Memory Extraction has NOT been migrated yet.

Current behavior:

```text
Companion.chat()
    ↓
Gemini response
    ↓
_memory extraction
    ↓
return reply
```

The extraction step is currently synchronous.

Moving it directly to the local model could approximately double response latency because the local model currently takes around 10 seconds for a short response.

Therefore:

> **Step 7 MUST NOT migrate Memory Extraction to Local Provider.**

Future milestone:

```text
Async Memory Extraction
        ↓
Local Memory Extraction
```

```text

B — Regression
C — Existing Subsystem Bug
D — Model Quality Difference
```

Document and evaluate separately unless it blocks migration.
