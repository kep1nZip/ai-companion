```text

        ↓

        ↓
```

```text
        ↓

        ↓

        ↓
```

## 4. Core Goals

### Goal A — Smarter Initiative Decisions

Initiative tidak hanya bergantung pada satu skor sederhana.

Decision dapat mempertimbangkan:

```text
opportunity
recent interaction
cooldown
emotion
energy
relationship
context relevance
conversation activity
```

Namun scoring harus tetap:

```text
simple
explainable
measurable
```

Jangan membuat sistem scoring kompleks tanpa evidence.

### Goal B — Interruption Awareness

Arona perlu membedakan:

```text
Teacher sedang idle
```

dengan:

```text
Teacher sedang aktif / sibuk
```

Vision dapat menjadi salah satu input, tetapi Vision tidak boleh langsung memulai percakapan.

### Goal C — Conversation Cooldown

Setelah Arona baru saja berbicara:

```text
jangan langsung autonomous speak lagi
```

Tujuan:

```text
avoid spam
avoid interruption fatigue
```

Cooldown harus configurable dan measurable.

Jangan memilih angka cooldown arbitrer sebelum baseline penggunaan nyata tersedia.

### Goal D — Context-Aware Proactivity

Initiative harus dapat mengetahui apakah opportunity memiliki context yang cukup relevan.

Contoh:

```text
Vision:
Teacher sedang membuka game X

Memory:
Teacher pernah menyukai game X

Routine:
ada opportunity untuk menyapa

Initiative:
relevance tinggi

Decision:
boleh berbicara
```

Namun:

```text
Initiative
≠
generate dialogue
```

Kalimat tetap dibuat oleh Companion/LLM.

### Goal E — Natural Silence

Sukses Initiative bukan:

```text
Arona berbicara sesering mungkin
```

Sukses Initiative adalah:

```text
Arona berbicara ketika benar-benar ada alasan.
```

Karena itu:

```text
NO
```

adalah valid dan sering kali merupakan hasil yang benar.

# 7. Phase 1 — Recent Interaction Awareness

Initiative harus mengetahui apakah Teacher baru saja berinteraksi.

Contoh:

```text
Teacher baru saja mengirim pesan
        ↓
Arona membalas
        ↓
Immediate autonomous interaction
        ↓
probability / score turun
```

Informasi minimum yang mungkin digunakan:

```text
last Teacher interaction
last Arona response

time since last interaction
```

Reuse data existing apabila tersedia.

Jangan membuat persistent state baru jika runtime state yang ada sudah cukup.

# 8. Phase 2 — Cooldown Intelligence

Cooldown digunakan untuk melindungi Teacher dari proactive spam.

Conceptual:

```text
Autonomous response
        ↓
Cooldown begins
        ↓
Routine trigger
        ↓
Initiative rejects / lowers score
        ↓
Cooldown expires
        ↓
Initiative may evaluate again
```

Cooldown harus:

```text
visible
measurable
configurable
```

Namun default value harus dipilih berdasarkan baseline nyata.

# 22. Decision Gate

## PASS

v2.7 PASS apabila:

- [ ] Initiative decisions lebih context-aware.
- [ ] Cooldown bekerja.
- [ ] Recent interaction awareness bekerja.
- [ ] Relevant memory dapat meningkatkan decision secara tepat.
- [ ] Vision dapat menjadi signal tanpa menjadi orchestrator.
- [ ] Low-value opportunities lebih sering ditolak.
- [ ] High-value opportunities dapat diterima.
- [ ] No autonomous spam yang signifikan.
- [ ] Local AI bekerja.
- [ ] Gemini AI bekerja.
- [ ] GUI responsif.
- [ ] Shutdown normal.
- [ ] Tidak ada regression penting.

## CONDITIONAL PASS

Digunakan apabila:

- scoring masih perlu tuning,
- sebagian timing edge case belum sempurna,
- frequency proactivity masih perlu disesuaikan,
- quality tetap acceptable,
- semua limitation terdokumentasi.

## FAIL

FAIL apabila:

- Initiative berbicara terlalu sering secara sistematis.
- Cooldown tidak bekerja.
- Recent interaction diabaikan secara konsisten.
- Vision/Routine menghasilkan autonomous response secara langsung.
- Initiative menjadi orchestrator kedua.
- GUI freeze.
- Provider regression.
- Shutdown regression.
- Silent fallback muncul.

# 27. Final Principle

v2.7 bukan:

```text
"buat Arona lebih sering bicara."
```

v2.7 adalah:

```text
"buat Arona lebih pintar memilih kapan harus bicara."
```

Prinsip utama:

```text
Proactive ≠ intrusive.
Frequent ≠ intelligent.
Silence can be the correct decision.
```

Dan tetap:

```text
Measure first.
Prefer simple decisions.
Protect Teacher's attention.
Keep boundaries explicit.
Do not over-engineer.
```

Setelah v2.7 selesai, milestone berikutnya ditentukan berdasarkan hasil penggunaan nyata dan kualitas proactive interaction, bukan sekadar jumlah autonomous responses.
