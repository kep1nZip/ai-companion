# Objective

Introduce a Behavior Engine.

The Behavior Engine gives Arona an internal state.

It does NOT generate responses.

It does NOT replace Gemini.

It does NOT replace Memory.

It simply models Arona's current condition.

# Responsibilities

emotion.py

Represents Arona's current emotion.

Examples

Happy

Sad

Excited

Embarrassed

Worried

Thinking

Emotion is short-lived.

---

mood.py

Represents long-term mood.

Examples

Cheerful

Calm

Sleepy

Energetic

Lonely

Curious

Mood changes slowly.

---

relationship.py

Represents relationship with Teacher.

Possible values

Trust

Comfort

Affection

Respect

Familiarity

Relationship grows over many conversations.

Relationship never resets automatically.

---

energy.py

Represents Arona's current energy.

Range

0

↓

100

Energy influences speaking style.

Energy changes gradually.

---

curiosity.py

Represents interest.

Examples

Teacher mentions new hobby

↓

Curiosity increases

↓

Future conversations may ask about it.

Curiosity decays naturally.

---

initiative.py

Represents willingness to start conversations.

If conversation is idle

↓

Initiative increases

↓

Arona may start chatting.

---

behavior_state.py

Single immutable object.

Contains every current behavior state.

Example

BehaviorState

emotion

mood

energy

trust

curiosity

initiative

timestamp

Nothing else.

---

behavior_engine.py

Coordinates every subsystem.

Never communicates with Gemini.

Never communicates with Avatar.

Never communicates with GUI.

Never communicates with Voice.

Produces BehaviorState only.

# Memory Integration

Behavior Engine should never query SQLite directly.

Behavior Engine requests data through MemoryManager.

MemoryManager remains the single source of memory.

---

# Avatar Integration

Behavior Engine never controls expressions directly.

Flow

BehaviorState

↓

AvatarManager

↓

HaloMapper

↓

Expression

↓

VTube Studio

---

# Voice Integration

Behavior Engine never performs TTS.

BehaviorState may influence future speaking style.

Example

Low Energy

↓

Slower speech

Excited

↓

Faster speech

Only if future APIs support it.

---

# GUI

GUI must remain unchanged.

Behavior Engine has no Qt dependency.

Qt imports remain inside ui/.

---

# Persistence

Behavior state should eventually be saved.

However

Persistence is NOT part of this milestone.

Architecture only.

---

# Threading

Behavior Engine must remain lightweight.

No background threads.

No websocket.

No blocking operations.

---

# Logging

Behavior changes should be logged.

Examples

Emotion Changed

Mood Changed

Relationship Increased

Energy Updated

Curiosity Increased

Initiative Triggered

---

# Error Handling

Behavior failures must never interrupt conversation.

If Behavior Engine fails

Conversation continues.

Voice continues.

Avatar continues.

Memory continues.

Behavior simply falls back to defaults.
