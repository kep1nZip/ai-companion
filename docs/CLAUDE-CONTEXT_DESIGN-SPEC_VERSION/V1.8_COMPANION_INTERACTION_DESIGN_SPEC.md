# 3. Core Architecture Rules

## Companion

Single primary orchestrator.

## ContextBuilder

Single runtime-context assembly boundary.

## PromptBuilder

System prompt construction only.

## Gemini

The only language-generation model in the interaction pipeline.

## Developer Tools

Read-only observation.

## GUI

Presentation + user control.

## Vision

Context provider.

## Routine

Opportunity/event generator.

## Initiative

Decision on whether autonomous interaction is permitted.

## Memory

Persistent/contextual user information.

## Behavior

Runtime emotional/internal state.

## Voice

Speech input/output.

## Avatar

Visual reaction layer.

# 7. Autonomous Interaction Pipeline

This is the most important v1.8 addition.

```text
Routine / existing trigger
        ↓
Initiative evaluation
        ↓
DecisionResult
        ↓
Should Start?
        │
    ┌───┴───┐
    NO      YES
    │        │
    ▼        ▼
  Stay     Companion
  quiet       ↓
           ContextBuilder
               ↓
             Gemini
               ↓
             Reply
               ↓
         Voice / Avatar
```

Initiative decides whether interaction is allowed.

It does **not** generate the sentence.

# 8. Autonomous Permission Policy

Absolute rule:

> **Initiative decides whether Arona may speak. Gemini decides what Arona says.**

Never:

```text
Initiative → sentence
Routine    → sentence
Vision     → sentence
```

Correct:

```text
Initiative
    ↓ YES
Companion
    ↓
ContextBuilder
    ↓
Gemini
    ↓
Arona response
```

# 12. Vision Integration

Vision provides environment context.

Example:

```text
Vision: Teacher is using VSCode/Python.
```

This may influence:

```text
Routine suppression
Initiative decision
Gemini context
```

Vision must not directly:

```text
start chat
control avatar
control voice
modify relationship
```

Auto Vision v1.5.2 remains a passive context refresher. It must not become an autonomous conversation trigger by itself.

---

# 13. Routine Integration

Routine creates an opportunity.

Example:

```text
Routine: Idle Chat eligible
```

This does **not** mean:

```text
Arona must talk
```

Correct:

```text
Routine
 ↓
opportunity
 ↓
Initiative
 ↓
decision
```

Do not make Routine generate language.

# 30. Error Handling

Autonomous interaction failure must not crash the application.

If Gemini fails:

```text
log
recover
wait for next interaction
```

If TTS fails:

```text
text response remains available
```

If Avatar fails:

```text
text/voice remain available where possible
```

One output layer must not take down the whole companion.
