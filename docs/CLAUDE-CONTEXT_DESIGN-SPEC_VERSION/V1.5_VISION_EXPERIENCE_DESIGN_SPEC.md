## 2. Objective

Make the existing Vision capability usable and understandable to Teacher.

Target capabilities:

- Vision ON/OFF.
- Manual capture.
- Vision status.
- Last capture status.
- Freshness/age information.
- Privacy indicator.
- Existing VisionContext influencing normal Arona replies.
- Optional AUTO mode only if the existing architecture already supports it safely.

No second Vision pipeline.

---

## 3. Core Philosophy

Vision gives Arona context, not language.

```text
Screen
  ↓
Existing Vision System
  ↓
VisionContext
  ↓
ContextBuilder
  ↓
Gemini
  ↓
Arona
```

Vision must NOT:

- generate replies;
- decide what Arona says;
- directly mutate BehaviorState;
- control Avatar;
- control Voice;
- create memory automatically;
- bypass ContextBuilder.

---
