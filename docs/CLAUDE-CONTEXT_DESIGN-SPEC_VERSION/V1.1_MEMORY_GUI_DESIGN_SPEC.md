```text

✗ Edit memories
```

# 10. Snapshot / DTO Boundary

Prefer immutable/read-only data crossing from backend to GUI.

Conceptually:

```python
@dataclass(frozen=True)
class MemoryItem:
    id: str
    content: str
    category: str
    created_at: datetime
```

and:

```python
@dataclass(frozen=True)
class MemorySnapshot:
    items: tuple[MemoryItem, ...]
    total: int
```

However:

> Do not invent fields that the actual Memory backend does not provide.

If the existing memory only has content/category/timestamp, do not invent an ID or other metadata.

The actual database/model is the source of truth.

# 37. Critical Regression Lesson

A previous project issue involved accidentally creating duplicate method definitions instead of modifying an existing method.

Therefore:

> If a requested change involves adding a parameter or behavior to an existing method, locate the existing definition and edit it. Never create a second definition with the same name.

After editing, search for duplicate definitions.
