# 5. Settings Classification Policy

Setiap konfigurasi yang ditemukan harus diklasifikasikan menjadi:

### A. Runtime Editable

Dapat diubah saat aplikasi berjalan.

Contoh hipotetis:

```text
Theme
Developer Mode
UI preference
```

### B. Startup Editable

Bisa diubah melalui GUI, tetapi perubahan baru aktif setelah restart.

Contoh hipotetis:

```text
AI model
API provider
certain speech configuration
```

### C. Read Only

Hanya ditampilkan.

Contoh hipotetis:

```text
Application Version
Installed Model
Runtime Status
```

### D. Secret

Tidak boleh ditampilkan secara mentah.

Contoh:

```text
GEMINI_API_KEY
VTube Studio token
```

### E. Unsupported

Tidak boleh muncul di GUI.

Kalau backend belum memiliki kontrak konfigurasi yang aman, jangan membuat UI palsu.
