# 5. Why Not Everything Local Yet

Do NOT interpret `AI_PROVIDER=local` as "everything is offline".

Current reality:

```text
Language generation → Local
Vision              → Gemini
Memory Extraction   → Gemini
TTS                 → Gemini
```

Vision and Memory Extraction remain Gemini because the current LocalProvider is not yet a safe image-capable provider, Vision/chat can compete for local resources, Vision output parsing has been validated with Gemini, and Memory Extraction is currently synchronous and would add significant latency if moved directly to Local.

Do not migrate these subsystems during Step 9.

# 10. Applying Provider Changes

Before implementing live switching, inspect the current architecture.

Preferred:

```text
Teacher changes provider
        ↓
Validate configuration
        ↓
Save provider selection
        ↓
Restart required if provider is constructed only at startup
```

If the application constructs the provider only once during startup:

> **Do NOT implement hot-swapping just for convenience.**

Display a restart-required message instead.

# 11. No Runtime Companion Rebuild

Do NOT destroy and recreate Companion, Conversation, or provider objects merely because the provider setting changed.

Prefer:

```text
Change setting
    ↓
save
    ↓
restart
    ↓
new provider
```

# 12. Validation Before Apply

When selecting Local, verify what the existing architecture can safely verify, such as endpoint/model configuration.

Do not invent a new health-check subsystem merely for Settings.

# 13. Local Provider Unavailable

If Local is selected but LM Studio is unavailable:

```text
Local provider unavailable.
Please start LM Studio and try again.
```

Do NOT silently switch to Gemini.

# 14. Gemini Provider Unavailable

Likewise, report Gemini failure clearly. Do not silently switch to Local.

# 15. No Silent Fallback

Silent fallback is explicitly disallowed.

```text

       ↓

       ↓
❌ silently use Gemini
```

This creates misleading behavior and makes debugging difficult.
