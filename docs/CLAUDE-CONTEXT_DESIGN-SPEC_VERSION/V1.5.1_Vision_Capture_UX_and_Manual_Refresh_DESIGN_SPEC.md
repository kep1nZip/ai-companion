AI Companion (Arona)
v1.5.1 — Vision Capture UX & Manual Refresh Context

Status: PLANNED — NOT IMPLEMENTED

v1.5 sudah mengimplementasikan Vision Experience dengan mode Manual.

v1.5.1 bertujuan memperbaiki UX capture dan menetapkan fondasi yang aman untuk mode Auto di masa depan tanpa membuat scheduler Vision baru.

PENTING: v1.5.1 bukan Vision System v2 dan bukan Auto Vision implementation.

1. Current v1.5 Reality

Berdasarkan inspeksi v1.5:

Vision
├── OFF / ON → GUI-only state
├── Manual mode → tersedia
├── Capture Screen → tersedia
└── AUTO → BELUM ADA

Vision tidak memiliki:

enable()
disable()
is_enabled

Vision.refresh() hanya dipanggil melalui:

Companion.capture_vision()

dan jalur capture tersebut saat ini berasal dari aksi manual GUI. Companion.chat() hanya memanggil:

Vision.get_context()

yang membaca cache fresh tanpa melakukan capture baru.

2. Tujuan v1.5.1

Tujuan v1.5.1:

Mempertahankan Manual Capture sebagai mode utama.
Menambahkan tombol Capture Now / Refresh yang selalu tersedia ketika Vision ON.
Memperjelas status apakah Vision Context masih fresh.
Membuat UX capture lebih eksplisit.
Menambahkan fondasi UI yang nantinya bisa dipakai untuk Auto Mode.
Tidak membuat scheduler Auto.
Tidak mengubah vision/* backend kecuali perubahan minimal benar-benar diperlukan.
3. Filosofi

4. Capture Now Policy

Saat Vision ON:

[ Capture Screen ]

atau:

[ Capture Now ]

harus tetap terlihat walaupun future UI nantinya memiliki mode lain.

Capture Now berarti:

Paksa Vision.refresh() sekarang.

Tidak berarti:

start scheduler

Tidak berarti:

enable continuous vision

Tidak berarti:

ubah Behavior

10. Vision Context Reuse

Normal Chat tetap menggunakan:

Companion.chat()
    ↓
Vision.get_context()

Jangan mengubah behavior ini.

Jika context masih fresh:

No new capture.
Reuse existing context.

Jika stale:

No automatic capture.

Karena v1.5.1 belum memiliki Auto scheduler.

11. Capture Now vs Chat

Important:

harus menjadi aksi eksplisit.

Jangan membuat:

Teacher sends chat

Vision automatically captures

12. Vision OFF

Saat OFF:

dan:

13. Known v1.5 Limitation

v1.5 memiliki limitation:

Capture
 ↓
Context masih fresh
 ↓
Teacher OFF
 ↓
Companion.chat()

masih bisa memakai context lama sampai TTL habis, karena toggle ON/OFF adalah GUI-only dan Companion tidak mengetahui status GUI.

v1.5.1:

JANGAN memperbaiki ini dengan mengubah Companion.chat() secara otomatis.

Karena itu merupakan backend architecture change.

Jika nanti user ingin:

OFF = immediate hard block

buat sebagai design milestone terpisah.

14. Auto Mode — Explicitly Deferred

v1.5.1 tidak mengimplementasikan Auto Vision.

Alasan resmi:

tidak ada scheduler Vision existing;
IdleScheduler milik Avatar bukan scheduler generik;
RoutineScheduler milik Routine bukan Vision scheduler;
membuat scheduler baru berarti architecture addition;
Vision.refresh() adalah blocking/network-bound.

Hal tersebut sudah ditemukan dalam inspeksi v1.5.

15. Future Auto UX Foundation
