## 3. Alasan Setiap Perubahan

### File baru — `ai/temporal_signals.py`
Pola IDENTIK `ai/reference_signals.py` (v3.3) & `ai/memory_ranking.py` (v3.4): pure function, TIDAK ADA LLM/network/state baru.

- `detect_relative_time_terms()` — 14 istilah waktu relatif (leksikal murni), termasuk istilah SAMAR ("nanti", "minggu depan") yang tetap dilaporkan sebagai raw signal tanpa pernah dinormalisasi.
- `normalize_relative_dates(text, now)` — HANYA 4 istilah yang benar-benar tidak ambigu secara kalender: "hari ini"(+0), "besok"(+1), "lusa"(+2), "kemarin"(-1). "minggu depan"/"bulan depan" SENGAJA tidak dinormalisasi (butuh keputusan tambahan yang bukan aritmatika kalender biasa lagi).
- `detect_continuation_cues()` / `detect_completion_cues()` / `detect_unresolved_cues()` — regex word-boundary, diurutkan spesifik→generik dengan bookkeeping non-overlap (`_add_first_match`) supaya "masih ngerjain" tidak dilaporkan dobel sebagai "masih ngerjain" + "masih" terpisah.
- **Detail penting (T08 No False Completion):** `\bselesai\b` dengan word-boundary TIDAK match "selesaikan" (kata perintah) — perbedaan makna gramatikal ("sudah selesai" vs "tolong selesaikan") tertangani otomatis oleh regex yang benar, tanpa logic tambahan apa pun.
- `TemporalSignals` (frozen dataclass) — 5 field, SEMUA berupa tuple evidence (relative_terms, normalized_dates, continuation_cues, completion_cues, unresolved_cues). **TIDAK ADA field `task_status`/`deadline`/`priority`/`is_active` di mana pun** (Hard Boundary §4.2/§4.3, diverifikasi test T11 lewat pengecekan pola field/key sungguhan, bukan cuma substring).
- `format_memory_age(updated_at, now)` — Phase 8, label usia ringkas ("~2 jam lalu"). Murni tampilan, tidak pernah mengubah status/menghapus memory.

### `ai/context_builder.py`
`build()` dapat parameter opsional `temporal_signals: Optional[TemporalSignals] = None` — **ContextBuilder TETAP assembly-only**: deteksi sinyal dilakukan Companion SEBELUM memanggil `build()` (pola identik `vision_context`/`routine_event`/`decision_result` yang sudah ada), method ini cuma merangkai teks lewat `_format_temporal()`. Section "Temporal Context" HANYA muncul kalau `not temporal_signals.is_empty()` — tidak menambah noise untuk pesan yang memang tidak mengandung sinyal apa pun.

### `ai/companion.py`
1. `_build_contents()` — menghitung `temporal_signals = detect_temporal_signals(user_input, now=...)` SEKALI dari pesan Teacher yang SEDANG diproses (bukan riwayat, bukan balasan Arona), diteruskan ke `ContextBuilder.build()` dan di-cache ke `self._last_temporal_signals` untuk dashboard.
2. `_build_autonomous_contents()` — **TIDAK disentuh sama sekali** (Phase 19: autonomous turn tidak boleh mengarang sinyal temporal Teacher karena memang tidak ada pesan Teacher baru di situ).
3. `_format_memories()` — parameter `now` opsional baru; kalau diisi, tiap baris memory dapat sufiks usia lewat `format_memory_age()`. Default `None` = perilaku identik sebelum v3.5 (backward-compat).
4. `get_temporal_debug_snapshot()` — method baru, read-only, reuse `_last_temporal_signals` + `_recall_decision_history[-1]` (field "Anchor" adalah ECHO dari recall v3.3/v3.4 TERAKHIR, bukan tracking topic baru).

### `developer/developer.py` + `ui/developer.py`
Field `temporal_debug` ditambah ke `DeveloperSnapshot`, ditampilkan sebagai section TAMBAHAN di card **"Memory Decisions"** yang sudah ada (spec §17 eksplisit: "Do NOT create a separate Temporal Dashboard") — bukan card/tab baru.
