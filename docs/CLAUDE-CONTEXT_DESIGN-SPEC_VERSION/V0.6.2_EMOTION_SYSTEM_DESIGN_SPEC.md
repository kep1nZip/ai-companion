# Objective

Introduce a true Emotion System.

The Emotion System represents Arona's current emotional state.

It is NOT merely emotion detection.

It is NOT a sentiment analyzer.

Emotion is an internal state that evolves through conversation.

---

# Responsibilities

emotion.py

Coordinates the Emotion System.

Provides public interface.

No AI calls.

No GUI.

No Avatar.

No Voice.

---

emotion_state.py

Represents Arona's current emotion.

Immutable object.

Contains

Current Emotion

Intensity

Timestamp

Previous Emotion

Reason

Duration

Nothing else.

---

emotion_analyzer.py

Analyzes conversation context.

Input

User message

Conversation context

Behavior state

Memory (via MemoryManager)

Output

Emotion Transition Proposal

Does NOT modify emotion directly.

---

emotion_rules.py

Contains transition rules.

Examples

Happy

↓

Calm

after inactivity

Excited

↓

Happy

after speaking

Sad

↓

Calm

over time

Embarrassed

↓

Happy

if Teacher praises Arona

No AI logic.

Only transition rules.

---

emotion_history.py

Stores previous emotion changes.

Used for future analysis.

Not persistent in this milestone.

SQLite integration comes later if needed.
