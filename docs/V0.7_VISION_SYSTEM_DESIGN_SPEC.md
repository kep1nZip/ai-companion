# Success Criteria

Vision works independently.

Manual capture succeeds.

Gemini Vision returns natural descriptions.

Vision Context is generated correctly.

ContextBuilder combines

Behavior Context

+

Vision Context

Companion sends the combined runtime context to Gemini.

Prompt files remain unchanged.

Behavior remains unchanged.

Avatar remains unchanged.

Voice remains unchanged.

No screenshots are stored.

No database changes occur.

No architecture redesign is required.

If implementing Vision requires redesigning Behavior, Companion, PromptBuilder, ContextBuilder, MemoryManager, Avatar, Voice, or GUI,

the implementation is considered architecturally incorrect.
